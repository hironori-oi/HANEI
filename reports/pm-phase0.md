## 0. エグゼクティブサマリー

英語初学者の小学6年生が **半年（180日）で英検3級合格** に到達することを真のKPIに据えたWebアプリ。
Phase 1 MVPでは「受験日逆算 → 日次1時間プラン → 適応出題 → AIコーチ誤答解説 → 進捗可視化」のコアループを **8〜10週で出す** ことを目標とする。

| 項目 | 値 |
|------|----|
| Phase 1 MVP 期間目標 | **8〜10週**（W1〜W10、1名稼働換算） |
| Phase 1 MVP WBS 合計人日 | **約 48.5 人日**（≒9.7週、1日0.5人日バッファ込み） |
| ユーザーストーリー総数 | **24本**（学習者11 / 保護者6 / 管理者7 / うち MUST 17） |
| 受入基準（Acceptance Criteria） | **24項目**（PRJ-014/015フォーマット踏襲＋子ども向け固有6項目） |
| 真のKPI | **小6初学者の英検3級合格率（β10名想定で5名以上 = 50%以上）** |
| Phase 1 リリース判定 KPI（プロキシ） | 4級レベル模試 70%以上正答 / 連続学習日数中央値10日以上 |
| 最大リスク | (1) 半年で3級到達の科学的妥当性、(2) AIコーチの安全性、(3) 問題プール構築遅延、(4) 13歳未満同意フロー法務 |

## 1. MVPスコープ確定（MoSCoW）

### 1.0 真のKPIに直結する機能の絞り込み原則

「半年で英検3級合格」というKPIから逆算すると、Phase 1 MVPに必須なのは以下の4軸：

1. **受験日逆算プラン**: 受験日と現在地を結ぶ「いつ・何を・何分やる」が日次で出ること
2. **適応出題エンジン**: 本人レベルを推定し、正答率70〜80%帯（学習効率最大）の問題を自動出題できること
3. **誤答解説AIコーチ**: 解説の質が「家庭教師」レベルでないと、誤答が学習に変換されない
4. **継続装置（ゲーミフィケーション）**: 180日続かなければゴール到達不可。連続記録 / レベル / 達成感の最低限の継続UX

それ以外（キャラ着せ替え、発音判定、SNS共有、保護者リマインドメールなど）は **Phase 2 以降** に倒す。

#### US-L03 受入基準（代表例）
- **Given**: 学習者が初期診断を完了済み（推定レベル「4級スタート」）
- **When**: 受験日「2026-10-04」を登録する
- **Then**: 残り日数（例: 161日）が表示され、Day1〜Day161 の各日に語彙/文法/リスニング/読解/ライティングの配分とノルマ（例: 「Day1: 新規語彙20語 + 文法問題10問 + リスニング5問」）が事前生成される。

#### US-L06 受入基準
- **Given**: 学習者が語彙問題で誤答した
- **When**: 「解説を見る」をタップする
- **Then**: 3秒以内にAIコーチが、(a) 誤答の選択肢がなぜ違うか、(b) 正解の意味と例文、(c) 関連語、を **小学6年生が理解できる語彙レベル**（漢字にはふりがな or やさしい語に置き換え）で日本語表示する。

#### US-L09 受入基準
- **Given**: 学習者が今日の60分プランの最後の問題を完了した
- **When**: 完了画面を表示する
- **Then**: (a) 連続日数 +1 表示、(b) 取得XP表示、(c) レベルアップ時はアニメーション、(d) バッジ獲得時は専用演出、を1秒以内に開始する。

#### US-P01 受入基準
- **Given**: 未登録の保護者がトップページにアクセス
- **When**: メールアドレスを入力 → 認証メールのリンクをクリック → 「保護者として子どもの学習に同意する」チェック → ニックネーム/学年を入力
- **Then**: 保護者ユーザーと子どもプロフィールが紐づいた状態で作成され、子どもアカウントは独立してログイン可能。**保護者の同意ログ**（IP / 日時 / 同意文言バージョン）がDBに記録される。

#### US-P06 受入基準
- **Given**: 保護者がログイン中
- **When**: 「子どものアカウントを削除する」を選択 → 確認モーダル → パスワード再入力
- **Then**: 30日以内に学習履歴・誤答ログ・チャット履歴・保護者同意レコードを論理削除→物理削除し、削除完了をメール通知する。

## 5. 半年で英検3級合格の学習スケジュール骨子

### 5.1 180日 × 60分/日 = 約180時間 配分

| 期間 | フェーズ | 主目標 | 60分の重点 | 累計時間 |
|------|---------|--------|------------|----------|
| **Day 1-30**（30時間） | 5級レベル定着 | 語彙600（基本動詞・人称代名詞・be動詞・現在形）+ 基本文型 | 語彙20分 / 文法20分 / リスニング15分 / 読解5分 | 0→30h |
| **Day 31-90**（60時間） | 4級レベル定着 | 語彙+700（過去形・未来形・進行形・can/must/may・接続詞・比較）+ 文法 + リスニング | 語彙15分 / 文法20分 / リスニング20分 / 読解5分 | 30→90h |
| **Day 91-150**（60時間） | 3級レベル本番演習 | 語彙+800（現在完了・受動態・関係代名詞・動名詞・不定詞・仮定法導入）+ 過去問 + ライティング25-35語 | 語彙10分 / 文法10分 / リスニング15分 / 読解+ライティング25分 | 90→150h |
| **Day 151-180**（30時間） | 仕上げ + 模試 + 面接対策 | 弱点補強 / 模試3回以上 / 面接フレーズ40件 | 模試・過去問演習40分 / 弱点補強20分 | 150→180h |

### 5.2 標準モデル: 1日60分の内訳（Day 1-150 デフォルト）

```
00-15分: 語彙学習（SRS再復習10語 + 新規10語）
15-30分: 文法学習（4択穴埋め10〜15問 + 誤答解説）
30-45分: リスニング学習（短文音声10問 + 速度調整 + シャドーイング許容）
45-60分: 読解+ライティング（短文読解5問 OR ライティング1本25-35語）
```

> Day 151-180 では模試演習40分 + 弱点補強20分の **試験慣れ重視モード** に自動シフト。

### 5.3 AIコーチによる動的配分調整の設計指針

**判定ルール（Phase 1 ルールベース → Phase 2 で機械学習化）**:

1. **直近7日の各技能正答率を集計**
   - 70-80%帯 = 適正、SRSで継続
   - <60% = 弱点、+10分/日その技能を増やす（他を削る）
   - >85% = 余裕、難易度を1段階上げる
2. **連続学習日数で配分調整**
   - 連続0〜3日 = ゲーミフィケーション要素を厚く（達成感優先）
   - 連続4-14日 = 標準配分
   - 連続15日以上 = 弱点重点モード解禁
3. **受験日カウントダウンで配分調整**
   - 残90日以上 = 学習フェーズ通常配分
   - 残90-30日 = 模試頻度アップ（週1回 → 週2回）
   - 残30日以下 = 模試＋面接対策モード（自動切替）
4. **AIコーチによる学習者個別補正**
   - 質問頻度が高いトピック = そのトピックの学習比率を一時的にUP
   - 誤答解説後の再出題で正答 = mastery_score 加点 → 出題頻度減
   - 直近のライティング添削で同じ文法ミス3回 = 該当文法復習を翌日プランに自動投入

**Phase 1 実装範囲**: 上記1, 3 はルールベースで実装。2 は連続日数表示のみ。4 はログ蓄積のみ（Phase 2 でロジック実装）。

## 10. まとめ

- Phase 1 MVP は **48.5人日 / 約10週** で出すことが現実的（並列作業が機能する前提）。
- 真のKPI「半年で英検3級合格」を支えるための **必須コアループ4軸**（受験日逆算 / 適応出題 / AIコーチ誤答解説 / 継続装置）を Must に厳格に絞った。
- 最大リスクは **問題プール1,600問の品質と量産速度**、および **AIコーチ品質** の2点。Phase 0 終了までにresearch部門の量産プロトコルとgpt-5-mini品質検証を完了させることがGate通過の必須条件。
- 受入基準24項目は PRJ-014/015 を踏襲しつつ、子ども向け固有6項目（タップ領域 / 文字サイズ / 同意フロー / AI安全性 / 応答時間 / コスト）を追加。
- W4中間レビュー / W8機能完成レビュー / W10リリースゲートの3段ゲートで縮退判定する設計とした。
