# PRJ-016 デザインコンセプト（Phase 0）

- **案件**: PRJ-016 小学生向け英語学習Webアプリ（仮称）
- **作成**: デザイン部門 / 2026-04-26
- **対象**: 小学校4〜6年生（特に小6・半年で英検3級合格） + 保護者
- **コア体験**: 毎日1時間 楽しく続く × 自己肯定感が上がる × 英検3級が確実に取れる
- **設計方針**: AI感を出さない / 子どもが毎日触りたくなる / 保護者にも信頼される / 子どもっぽさだけに振らず「かわいい × 上質」
- **技術前提**: Next.js (App Router) + TypeScript + shadcn/ui + Tailwind + next-themes + Framer Motion + Heroicons（補助 Lucide）+ Howler.js

> 本書は CEO/オーナー上申用のデザインコンセプト草案。確定後 `decisions.md` に転記し、Phase 1 で実装トークン（CSS 変数 / Tailwind config）に落とす。

### C 案. 「ステーショナリー × ノート」 — ミニマル文具系

| 項目 | 内容 |
|---|---|
| キーワード | ノート / 文具 / 図鑑 / 小さな研究室 |
| ムードボード | **色**: オフホワイト #F7F5F0 地、Primary **Indigo Ink #3B4B8A**、Accent **Coral #F08A7A**、Sub **Olive #8AA76A**。**形**: 罫線・付箋・マスキングテープ・スタンプ。**トーン**: 図鑑 / 学習帳のオマージュ |
| キャラ方向 | 擬人化文具系：万年筆コーチ「ペン先生」、消しゴムくん、付箋ねこ等。マスコットは脇役、主役はノート |
| ゲーミフィケーション | XP は「ノートにスタンプが押されていく」、streak は「日めくりカレンダー」、レベルアップは新しいページ解禁 |
| ターゲットフィット | 落ち着き / 上品さは最強、保護者の信頼は最大。一方、**毎日触りたくなる** ドーパミン設計はやや弱く、低学年には地味に映る |
| 推奨度 | ★★★★ |
| 理由 | 上質感は最高、AI感ゼロ、Web で再現しやすい。だが「自己肯定感を**上げる**」ためのキャラ感情が薄く、家庭学習の孤独感を緩和する力が A 案に劣る |

### 最終推奨: **A 案「ポップ × ジェントル」**

**理由 3 点**

1. 本案件のコア体験「自己肯定感を**上げる**」には、感情を返してくれるキャラの存在が決定的。A 案は B のような戦闘比喩を避けつつ、C より感情温度が高い。
2. 「かわいい × 上質」のスイートスポット。男女・小4〜小6・保護者すべてに違和感が少なく、英検3級合格まで半年伴走するのに耐える中性的トーン。
3. 紙質感ベースは AI 感が出にくく、Tailwind + shadcn/ui で再現性が高い。個人開発のリソース内で品質を出せる現実解。

> 以降のトークン / モック / モーション仕様は **A 案前提** で記述する。B / C 案を採用する場合は §2〜§6 を差し替える。

## 3. キャラクターシステム

### 3.1 キャスト

| キャラ | 役割 | 性格 | 主登場面 |
|---|---|---|---|
| **ことだまトリ** | メインAIコーチの可視化 | 落ち着いた / 励まし上手 / 控えめにユーモラス | ホーム / コーチチャット / 誤答解説 |
| **ことば犬** | 語彙担当サブ | ちょっと調子に乗りやすい / 元気 | 単語カード / streak 通知 |
| **ミミ（リスニング兎）** | リスニング担当サブ | 静か / 耳がいい | リスニング画面 |
| **ノート先生**（任意） | 文法解説の図解担当 | 真面目 / 落ち着いた大人キャラ | 文法解説 / 保護者ビュー |

### 3.2 表情パターン（最低 6）

各キャラ共通: `idle` / `cheer`（喜ぶ）/ `support`（応援する・腕を振る）/ `gentle-correct`（優しく訂正・首をかしげる）/ `level-up-celebrate`（紙吹雪と共に）/ `sleepy`（離脱日・streakが切れそう）/ `proud`（保護者ビューで）

### 3.3 生成戦略 — 推奨案

**A. ハイブリッド方式（推奨）**

1. **コンセプトアート段階**: gpt-image-2 / Midjourney 等でムード探索 → 5〜10 枚のラフを生成し方向性を高速確定
2. **キャラ確定段階**: 確定したメインキャラ 1〜2 体は **外部イラストレーター（フリーランス）に発注**して原画 + 表情差分 6 種 + ポーズ差分 4 種を作成。著作権**買い切り（譲渡）**で契約
3. **背景 / アイテム / バッジ素材**: AI 生成 + 手直しで量産可（コスト圧縮）
4. **モーション**: Lottie or Framer Motion で 2D アニメーション、**3D / リアル系は不採用**（AI感が出やすい）

**理由**: メインキャラだけは「魂」が要る、ここを AI 量産で済ませると「**AI感のあるアプリ**」と見なされ保護者の信頼を失う。バッジ等の量産素材は AI で十分。

**B. 全 AI 量産方式（NG）**: 著作権・スタイル一貫性・表情の感情解像度の 3 点で破綻する。**不採用**。

### 3.4 著作権・利用許諾の留意点

- 外部発注時: **著作権譲渡（27条/28条含む）** の契約必須。クレジット表記の有無を契約に明記。
- 商用利用 OK のフォント / 効果音のみ採用（Noto Sans JP / Zen Maru Gothic / Geist は OK、Nunito は OFL、効果音は freesound CC0 + 自作優先）。
- AI 生成画像: 利用規約で**商用 OK** のサービスのみ（gpt-image-2 系は OpenAI 利用規約に従う）。生成のみで配布する素材には別途検証。
- キャラ実装後はオリジナリティ確認（既存キャラとの類似チェック）を必ず通す。

## 4. ゲーミフィケーション UI 設計

### 4.1 進度システム

- **XP**: 各ミニタスクで +5〜+30、ボス（模試）で +200。
- **レベル**: Lv1〜Lv50。Lv = 英検級レンジに連動（Lv1〜10:5級、Lv11〜25:4級、Lv26〜50:3級）。
- **称号バッジ**: Bronze/Silver/Gold/Platinum（§2.1）+ 限定バッジ（「初めての満点」「リスニング7連続正解」等）。
- **streak**: 「**つぼみ → 花**」可視化。1日1ミッション完了で +1、休んでも 1日だけ「**おやすみ券**」で復活可（焦らせない設計）。
- **マイルストーン**: 30/60/90/180 日でキャラからの手紙。

### 4.2 スキルツリー / ロードマップ

**採用: 「ボード型 + 樹木型ハイブリッド」**

- ホームに表示するのは **「今日歩く道」** だけ（ボード型 / 横スクロール、3〜5 ステップ）→ 認知負荷を下げる
- 設定 / 進捗画面に **「樹木型・全体マップ」**（縦長スクロール、5級の根 → 4級の幹 → 3級の枝葉）→ 達成感・全体俯瞰
- **道のり型を不採用**にした理由: 一本道は脱線時に挫折感が出る。樹木型は「枝が複数あり、別の枝で先に進める」逃げ道がある

### 4.3 受験日カウントダウン

- ホーム最上部に**控えめに固定**（高さ 56px / shadcn `Card` ベース）
- 「**あと 87 日**」をディスプレイ書体で表示、隣に「**1日 60 分で間に合うペース**」のステータスを `accent` 色で
- カウントが 30 日を切ると、`info` で「**ラストスパート期間**」モードに切り替え（背景に細かい星のテクスチャ）
- **赤/警告色は使わない**（焦りを煽らない）

### 4.4 自己肯定感マイクロコピー指針

#### 原則

1. **行為を褒める、人格を褒めない**（成長マインドセット）: ×「天才！」 / ◯「8 個合ってる、すごい！」
2. **頑張りプロセスを言語化**: ◯「昨日より 2 問速く解けたね」
3. **失敗を学習機会として描く**: ×「不正解です」 / ◯「**ここに気づけたのは大きい！**もう一度一緒に見てみよう」
4. **比較相手は他人ではなく過去の自分**: ×「ランキング 5位！」（任意）/ ◯「7日前のあなたより、聴き取り正答率 +12%」
5. **絵文字は使わない**（記憶/feedback_no_emoji）。代わりにキャラの表情差分とアイコン（CheckIcon / SparklesIcon / ArrowTrendingUpIcon）で感情を伝える

#### NG / OK 例（実コピー）

| シーン | NG | OK |
|---|---|---|
| 正解 | 「正解！」 | 「いいね、考え方が合ってる」 |
| 不正解 | 「ちがいます」 | 「**おしい**、ここをもう一度見てみよう」 |
| streak 維持 | 「7日連続！すごい！」 | 「7日続いた、**続ける力**がついてきてる」 |
| 離脱復帰 | 「3日もサボった！」 | 「おかえり。今日 10 分だけ、一緒に始めよう」 |
| レベルアップ | 「レベルアップ！」 | 「Lv12 になった。**4級レンジに入ったよ**」 |
| 模試低スコア | 「点数が下がった」 | 「リスニングが伸びてる、文法はあと一歩。次の 1 週間でここを集中しよう」 |

## 6. モーション / インタラクション仕様

### 6.1 Framer Motion 使いどころ

| シーン | 仕様 | 抑制ライン |
|---|---|---|
| 正解 | キャラが 1 度だけ +12% スケール (320ms spring)、+XP 数字が下から fade-in、ボタンが緑のチェックに 220ms で morph | **紙吹雪は出さない**（連続正解で疲れるため、レベルアップに限定） |
| 不正解 | カードが 80ms × 3 で軽く左右シェイク（強さ控えめ）、キャラ表情のみ gentle-correct に切替、**赤のフラッシュ禁止** | 「失敗」を視覚で殴らない |
| レベルアップ | 全画面ホワイト → 紙吹雪 800ms → キャラ +新Lv の表示 → 自動で閉じる | 動画再生の強制は禁止、長くて 1.2s |
| streak 維持 | カレンダーの今日にスタンプが押される 220ms、つぼみが少し動く | 派手なエフェクトは出さない |
| 受験日カウント切替 | 30日 / 14日 / 7日 / 前日 のときだけキャラから一言、それ以外は数字が静かに変わるのみ | 毎日の演出はしない（疲労） |
| ページ遷移 | shadcn `Sheet` / `Dialog` 標準遷移 (220ms ease-out)、画面遷移は基本トランジションなし or 軽い fade（180ms） | カルーセル / 視差スクロール禁止 |
| キャラ idle | 2.5 秒に 1 回、瞬き or 軽く揺れる（Lottie） | ずっと動かない / ずっと動き続ける、を避ける |

### 6.2 「AI感を出さない」抑制ライン

- **グラデーションは1画面1か所まで**（受験日カードの背景のみ）。多用しない。
- **glassmorphism（曇りガラス）禁止**。
- **shadow は紙質感の柔らかい 2 層** のみ（§2.3 `shadow-card`）。Material 系の重い elevation は使わない。
- **ニュートラル背景（cream/ink）に高彩度を点で置く**設計。全面ベタ塗りカラフル禁止。
- **イラスト > 写真**。写真は使う場合も保護者向けセクションのみ。
- **過度な擬音テキスト（「ﾄﾞｰﾝ！」等）禁止**。

### 6.3 アクセシビリティ・モーション

- すべての celebrate / pop は `prefers-reduced-motion: reduce` 時にフェードのみへ縮退
- フォーカスリングは `outline-2 outline-offset-2 outline-[--primary]`、地色との比 3:1 以上を確認

### 8.5 Apple HIG（Kids Apps）

- **学べる点**: 保護者ゲート、Safe Area対応、決済導線の親同意、声の誘導
- **避けるべき点**: モバイル前提なので Web では文字サイズ・タップ領域で同等以上を確保
- 出典:
  - https://developer.apple.com/design/human-interface-guidelines
  - https://developer.apple.com/app-store/kids-apps/
  - https://education.apple.com/resource/250011856

### 8.6 Material Design 3（参考）

- **学べる点**: トークン階層、tangible surface、meaningful motion
- **避けるべき点**: bold graphics / 派手な elevation の濫用は AI 感に寄る → 本案件では抑制
- 出典:
  - https://medium.com/@shivaniy0211/apples-human-interface-guidelines-vs-google-s-material-design-guidelines-e28db15028c0
  - https://github.com/ehmo/platform-design-skills

### 8.7 WCAG 2.2（タップ領域 / 一般）

- **学べる点**: SC 2.5.8 で 24×24 が最低、AAA は 44×44。子ども向けはさらに **48×48 / CTA 56×56** を本案件基準とする
- 出典:
  - https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
  - https://www.smashingmagazine.com/2023/04/accessible-tap-target-sizes-rage-taps-clicks/

### 8.8 自己肯定感 / 成長マインドセット UX

- **学べる点**: ClassDojo / Seesaw / Khan Academy 等の「**プロセスを褒める**」フィードバック設計、目標分解
- **避けるべき点**: 結果のみのスコア演出（過剰な点数比較）は劣等感を生む
- 出典:
  - https://www.understood.org/en/articles/positive-self-esteem-kids-importance
  - https://pinecone.academy/blog/boosting-kids-confidence-how-technology-supports-self-esteem-and-emotional-resilience
