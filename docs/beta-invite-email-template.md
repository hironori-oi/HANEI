## 3. プレースホルダ一覧

| プレースホルダ | 差し込み内容 | 取得経路 |
|---|---|---|
| `{お名前}` | 受信者氏名 (敬称略 / 「○○ さま」で表示) | 手動入力 |
| `{INVITE_CODE_8_CHARS}` | 8 文字の英数招待コード | `bun run scripts/generate-beta-invite.ts` で発行 |
| `{オーナー個人 email}` | 問い合わせ用メールアドレス | オーナーが Phase 3 で確定するまでは仮アドレスでも可。LP footer の `mailto:` は `support@hanei.app` を採用済のため、特段の理由がなければ同一値に揃える |

---

## 4. 配布方法

1. **メール**: 既知の保護者向けには Resend (`RESEND_API_KEY` 既設定) または個人 Gmail から直接送付。
2. **DM**: SNS の DM 経由で個別配布する場合は、上記本文をそのまま貼り付け可能 (装飾依存ゼロ)。
3. **個別配布**: 紙面 / 口頭で招待コードのみ伝え、本文は本テンプレを案内する形でも可。

---

## 5. 招待コードの発行手順

```bash
cd projects/PRJ-016/app
bun run scripts/generate-beta-invite.ts
```

- 詳細は DEC-069 §F および `scripts/generate-beta-invite.ts` の冒頭コメントを参照。
- `BETA_INVITE_REQUIRED=true` を本番 Vercel Production env に設定済の前提で運用する。

## 6. 設計判断 (補助メモ)

- **DEC-024 罰則ゼロ厳守**: 「合格できる」「絶対に」等の断定回避 / 「目指す」「ご一緒に」の中立トーン。
- **DEC-005 訴求コピー強度準拠**: 「半年で英検3級を目指す」を起点。「合格保証」「合格できる」表記は β 実績待ち。
- **DEC-006 / DEC-012 整合**: 「β期間中は完全無料」「将来の有料化検討時もβ機能は無料継続予定」を明記。
- **invite code redeem 動線整合**: 「ご利用開始の手順」step 2 で T3-A 実装済の入力欄を明示誘導。
- **feedback 動線整合**: T3-B で実装済の「ご意見を送る」ボタンを本文で案内し、全ユーザーに認知させる。
